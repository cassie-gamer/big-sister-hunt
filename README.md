# Big Sister Hunt 🌲🍖

A forest adventure about a brave big sister!

## The Story

Once upon a time, there was a little boy, a little girl, and a big sister. One day they go into the forest... and the little brother and little sister say **"I'm hungry!"**

So the big sister — **that's YOU!** — goes to get some food. You have to hunt bears, snakes, and tigers, and collect **20 meat** to feed everyone!

## How to Play

- **Move** with WASD / arrow keys (or touch joystick)
- **Attack** with SPACE (or tap the Attack button) — swing at animals near you!
- **Bears** take 4 hits, **tigers** take 3 hits, **snakes** take 2 hits
- Each defeated animal drops **meat**
- Collect **20 meat** to win — then everyone eats! 🍖

## Unity Setup

1. Build a forest scene with bears, snakes, and tigers (each with `ForestAnimal.cs`, set the animal type)
2. Add `BigSister.cs` to the big sister character
3. Add `MeatCounter.cs` to a game manager object, hook up the UI text
4. Place plenty of animals — you'll need at least 20 meat worth!

Good luck, big sister! 🌲
